# Rashid Activity Monitor - Desktop App

تطبيق سطح مكتب لمراقبة نشاط الموظفين وإرسال البيانات لنظام مجموعة عبد الفتاح رشيد.

## المميزات

- ✅ تسجيل دخول الموظف بحسابه
- ✅ مراقبة النافذة النشطة كل 5 ثواني
- ✅ تسجيل اسم البرنامج وعنوان النافذة
- ✅ استخراج الروابط من المتصفحات
- ✅ تتبع وقت النشاط/عدم النشاط
- ✅ إرسال البيانات للسيرفر كل دقيقة
- ✅ يعمل في الخلفية (System Tray)
- ✅ واجهة عربية

## التثبيت والتشغيل

### 1. تثبيت المكتبات

```bash
cd desktop-app
npm install
```

### 2. تشغيل التطبيق (وضع التطوير)

```bash
npm start
```

### 3. بناء التطبيق للتوزيع

**لـ Windows:**
```bash
npm run build-win
```

سيتم إنشاء ملف التثبيت في: `dist/Rashid Activity Monitor Setup.exe`

**لـ Mac:**
```bash
npm run build-mac
```

**لـ Linux:**
```bash
npm run build-linux
```

## الاستخدام

1. افتح التطبيق
2. أدخل:
   - عنوان السيرفر (مثال: `http://localhost:3000` أو `https://arasgroup.app`)
   - البريد الإلكتروني
   - كلمة المرور
3. اضغط "تسجيل الدخول"
4. سيختفي التطبيق ويعمل في الخلفية
5. يمكنك الوصول للتطبيق من System Tray (أسفل اليمين)

## إيقاف/تشغيل المراقبة

- انقر بزر الماوس الأيمن على أيقونة التطبيق في System Tray
- اختر "إيقاف المراقبة" أو "بدء المراقبة"

## تسجيل الخروج

- انقر بزر الماوس الأيمن على أيقونة التطبيق
- اختر "تسجيل الخروج"

## البيانات المُرسلة

التطبيق يرسل البيانات التالية كل دقيقة:

- اسم البرنامج النشط
- عنوان النافذة
- الرابط (للمتصفحات)
- وقت البدء والانتهاء
- المدة بالثواني
- حالة النشاط (نشط/خامل)
- اسم الجهاز
- عنوان IP

## ملاحظات الأمان

- التطبيق **لا يسجل** كلمات المرور أو محتوى الكتابة
- يسجل فقط عنوان النافذة واسم البرنامج
- البيانات مشفرة عند الإرسال (HTTPS)
- يتطلب تسجيل دخول صالح

## المتطلبات

- Windows 10/11 أو macOS 10.13+ أو Linux
- اتصال بالإنترنت
- Node.js 16+ (للتطوير فقط)
